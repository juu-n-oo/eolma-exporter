# eolma 내보내기 개인정보처리방침

**시행일: 2026년 9월 2일**

eolma 내보내기(이하 “확장 프로그램”)는 이용자가 직접 요청한 네이버페이·쿠팡 결제 및 주문내역을 파일로 내보내거나, 이용자 본인의 eolma 가계부에 전송하는 도구입니다. 운영자 Dandi Works는 아래와 같이 정보를 처리합니다.

## 1. 처리하는 정보와 목적

확장 프로그램은 이용자가 네이버페이 또는 쿠팡의 지원 페이지에서 직접 실행한 경우에만, 화면에 표시된 다음 정보를 처리합니다.

- 판매자·가맹점명, 상품명, 결제·주문 금액, 일시, 주문 상태, 결제수단 등 결제·주문내역
- eolma 전송을 선택한 경우, 위 내역을 이용자 본인의 eolma 계정에 전송하기 위한 전송 결과

처리 목적은 다음 둘로 한정됩니다.

1. 이용자가 선택한 Excel 또는 CSV 파일을 이용자 기기에 다운로드
2. 이용자가 “eolma로 전송”을 직접 누른 경우, 해당 내역을 이용자 본인의 eolma 가계부 검토 대기함에 전송

확장 프로그램은 신용카드 번호, 계좌번호, 비밀번호를 수집하지 않으며, 네이버페이·쿠팡·eolma 외 웹사이트의 정보나 브라우징 기록에도 접근하지 않습니다.

## 2. eolma 로그인 정보 처리

eolma 전송은 이용자가 로그인해 열어 둔 `eolma.de` 탭을 통해서만 수행됩니다. eolma의 HttpOnly 인증 쿠키는 브라우저가 해당 탭의 같은 출처 요청에 자동으로 첨부할 뿐, 확장 프로그램은 쿠키·세션·인증 토큰을 읽거나 복사하거나 저장하지 않습니다.

따라서 eolma 탭이 열려 있지 않거나 해당 탭에서 로그인하지 않은 경우에는 전송할 수 없습니다.

## 3. 보관·전송·공유

- 다운로드만 선택하면 수집 내역은 파일 생성에 필요한 동안 브라우저 메모리에서만 처리되며, 확장 프로그램이 별도로 저장하거나 외부로 전송하지 않습니다.
- eolma 전송은 이용자의 명시적 실행이 있을 때만 HTTPS로 `https://eolma.de`의 이용자 본인 계정에 전송됩니다. 전송된 내역은 eolma 서비스의 개인정보처리방침을 따릅니다.
- 운영자는 이 정보를 판매·대여하거나 광고·프로파일링에 사용하지 않으며, 이용자 본인의 eolma 계정 전송 외 제3자에게 제공하지 않습니다.

## 4. Chrome Web Store 사용자 데이터 정책

확장 프로그램이 수신·처리하는 정보의 사용은 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)의 Limited Use 요건을 준수합니다. 즉, 위에 밝힌 이용자 요청 기능을 제공하는 데에만 사용하며, 개인화 광고·신용도 평가·데이터 판매·제3자 제공 목적으로 사용하지 않습니다. 사람의 열람은 이용자가 요청한 지원, 보안 조사 또는 법령상 필요한 경우에만 최소한으로 이뤄집니다.

## 5. 이용자의 선택과 삭제

이용자는 eolma 전송을 선택하지 않고 언제든 파일 다운로드만 이용할 수 있습니다. 확장 프로그램을 제거해도 확장 프로그램이 보관하는 계정·토큰·거래내역은 없습니다. eolma로 전송한 내역은 eolma 가계부에서 검토·삭제할 수 있으며, eolma 계정 및 전송된 데이터의 처리에는 [eolma 개인정보처리방침](https://github.com/juu-n-oo/eolma-docs/blob/main/privacy-policy.ko.md)이 적용됩니다.
