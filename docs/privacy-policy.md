# 개인정보처리방침 (Privacy Policy)

**마지막 업데이트**: 2026-05-21

## 개요

Eolma Exporter(이하 "본 확장 프로그램")는 사용자의 개인정보 보호를 최우선으로 합니다. 본 정책은 확장 프로그램이 어떤 정보를 수집하고, 어떻게 사용하는지 명확히 설명합니다.

---

## 1. 수집 정보

### 1.1 수집하는 정보

본 확장 프로그램은 다음 정보만 수집합니다:

- **결제/주문내역 데이터**: 네이버페이 또는 쿠팡 결제 페이지에서 볼 수 있는 공개 정보만 추출
  - 상점명, 상품명, 결제금액, 결제일시, 결제수단 등
  - **개인 식별 정보(이름, 전화번호, 주소 등)는 수집하지 않습니다**
  - 추출한 데이터는 즉시 Excel/CSV 파일로 변환되어 사용자 컴퓨터에 저장되며, 세션 간 보관되지 않습니다

### 1.2 수집하지 않는 정보

다음 정보는 **절대 수집하지 않습니다**:

- 사용자 이름, 전화번호, 주소
- 신용카드 번호, 계좌정보
- 비밀번호 및 보안 정보
- 브라우징 히스토리
- 다른 웹사이트 정보

---

## 2. 정보 사용

### 2.1 사용 목적

수집한 정보는 **다음 목적으로만 사용**됩니다:

1. **Excel/CSV 파일 생성**: 사용자가 요청한 형식으로 거래내역 다운로드

### 2.2 정보 공유

본 확장 프로그램은 사용자 동의 없이 제3자와 정보를 공유하지 않습니다.

---

## 3. 정보 보안

### 3.1 보안 조치

- 모든 데이터는 **사용자 브라우저 안에서만 처리**되며, 외부 서버로 전송되지 않습니다
- 추출한 데이터는 Chrome의 표준 다운로드 API를 통해 사용자가 지정한 위치에 직접 저장됩니다
- 개발자는 저장된 데이터에 **접근 불가**합니다

### 3.2 데이터 삭제

사용자는 언제든:
- 브라우저의 사이트 데이터 삭제로 로컬 저장소 제거
- 확장 프로그램 제거로 모든 데이터 삭제

---

## 4. 사용자 권리

사용자는 다음 권리를 가집니다:

1. **정보 열람**: 언제든 저장된 데이터 확인 가능
2. **정보 삭제**: 브라우저 설정에서 제거 가능

---
