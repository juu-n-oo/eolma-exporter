# 개인정보처리방침 (Privacy Policy)

**마지막 업데이트**: 2026-06-10

## 개요

Eolma Exporter(이하 "본 확장 프로그램")는 사용자의 개인정보 보호를 최우선으로 합니다. 본 정책은 확장 프로그램이 어떤 정보를 수집하고, 어떻게 사용하며, 어떤 경우에 외부로 전송하는지 명확히 설명합니다.

---

## 1. 수집 정보

### 1.1 수집하는 정보

본 확장 프로그램은 다음 정보만 처리합니다:

- **결제/주문내역 데이터**: 네이버페이 또는 쿠팡 결제·주문내역 페이지에서 볼 수 있는 정보만 추출
  - 상점명, 상품명, 결제금액, 결제일시, 결제수단 등
  - 추출한 데이터는 사용자가 요청한 형식(Excel/CSV)으로 변환되거나, 사용자가 선택한 경우 eolma 가계부 서비스로 전송됩니다
- **eolma 로그인 토큰**: 사용자가 `eolma.de`에 직접 로그인한 경우, 로그인 상태 확인과 업로드를 위해 인증 토큰을 브라우저 로컬 저장소(`chrome.storage.local`)에 보관합니다
  - 이 토큰은 사용자 브라우저 안에만 저장되며, eolma 서버 외 다른 곳으로 전송되지 않습니다

### 1.2 수집하지 않는 정보

다음 정보는 **수집하지 않습니다**:

- 사용자 이름, 전화번호, 주소
- 신용카드 번호, 계좌정보
- 비밀번호 및 보안 정보
- 네이버페이·쿠팡·eolma 외 다른 웹사이트의 정보나 브라우징 히스토리

---

## 2. 정보 사용 및 전송

### 2.1 사용 목적

처리한 정보는 **다음 목적으로만 사용**됩니다:

1. **Excel/CSV 파일 생성**: 사용자가 요청한 형식으로 거래내역 다운로드
2. **eolma 가계부 전송(선택)**: 사용자가 직접 "eolma로 전송"을 실행한 경우에 한해, 수집한 거래내역을 **사용자 본인의 eolma 계정**으로 업로드. 업로드된 내역은 eolma 가계부에서 사용자가 검토 후 등록합니다

### 2.2 외부 전송

- 데이터가 외부로 전송되는 경우는 **사용자가 명시적으로 "eolma로 전송"을 실행한 때뿐**입니다
- 전송 대상은 **사용자 본인의 eolma 계정 서버(`https://eolma.de`)** 이며, 그 외 제3자에게 전송하거나 판매하지 않습니다
- eolma로 전송하지 않으면 데이터는 사용자 브라우저를 벗어나지 않습니다

---

## 3. 정보 보안

### 3.1 보안 조치

- 다운로드 데이터는 Chrome의 표준 다운로드 API를 통해 사용자가 지정한 위치에 직접 저장됩니다
- eolma 전송은 HTTPS로 암호화되어 사용자 본인의 eolma 계정으로만 이뤄집니다
- eolma 로그인 토큰은 브라우저 로컬 저장소에만 보관되며, 개발자는 사용자의 다운로드 파일·토큰에 **접근할 수 없습니다**

### 3.2 데이터 삭제

사용자는 언제든:
- 브라우저의 사이트 데이터 삭제 또는 eolma 로그아웃으로 로컬 저장된 토큰 제거
- 확장 프로그램 제거로 로컬에 저장된 모든 데이터 삭제
- eolma 계정에 업로드된 내역은 eolma 가계부 서비스 내에서 직접 삭제

---

## 4. 사용자 권리

사용자는 다음 권리를 가집니다:

1. **정보 열람**: 언제든 저장·전송된 데이터 확인 가능
2. **정보 삭제**: 브라우저 설정 또는 eolma 계정에서 제거 가능
3. **전송 선택권**: eolma 전송은 항상 사용자의 명시적 실행에 의해서만 일어남
