# 가계부 웹 서비스 기획서

## 개요

지출 내역 및 투자/저축 내용을 관리할 수 있는 웹 서비스. 네이버페이, 쿠팡 등 플랫폼별 결제내역을 브라우저 플러그인으로 추출하여 서비스에 업로드하고, 카테고리 분류와 재무 분석을 수행한다. MCP 서버를 제공하여 사용자가 자신의 AI 에이전트로 재무 상담을 받을 수 있도록 한다.

## 목표

### 1차 목표

기존 Google Spreadsheet 기반 가계부 워크플로우를 대체하는 본인용 도구를 만든다.

### 장기 목표

외부 사용자가 가입해서 사용할 수 있는 실제 서비스로 확장한다.

### 완료 기준 (Spreadsheet 대체 조건)

다음 네 가지를 모두 충족하면 기존 Spreadsheet 워크플로우를 대체할 수 있다:

1. 네이버페이/쿠팡/현대카드 데이터를 서비스에 넣을 수 있다
2. 카테고리 분류를 할 수 있다
3. 월별 지출을 카테고리별로 시각화해서 볼 수 있다
4. 월별 정리된 데이터를 CSV/엑셀로 내려받을 수 있다

## 배경 및 문제

### 현재 겪고 있는 문제

- 카드 사용내역에 "네이버페이", "쿠팡" 등 플랫폼명만 표시되고, 구체적 구매 품목이 나오지 않는다
- 플랫폼별로 데이터 형식이 다르고, export 기능이 제한적이다
- 개인 개발자는 금융 API(마이데이터 등)를 사용할 수 없다
- 시각화를 Obsidian 마크다운으로 하고 있어 커스텀하기 어렵다

### 현재 워크플로우 (이미 검증됨)

```
Chrome Extension (네이버페이/쿠팡)
    → Excel 추출
    → Google Spreadsheet (Apps Script로 파싱/정규화)
    → CSV 추출
    → Obsidian Vault 저장
    → DataviewJS 대시보드
    → Claude Code/Codex로 재무 상담
```

### 서비스화의 핵심 아이디어

이 검증된 워크플로우를 웹 서비스로 전환하되, 금융 API 없이도 동작하는 구조를 유지한다.

## 대상 사용자

- 가계부를 쓰고 싶지만, 수동 입력이 귀찮아서 포기한 사람
- 네이버페이/쿠팡 등 온라인 결제 비중이 높은 사람
- AI 에이전트를 활용해 재무 상담을 받고 싶은 사람
- 기존 가계부 앱이 제공하는 카테고리가 자신에게 맞지 않는 사람

## 서비스 구조

### 전체 아키텍처

```
[브라우저 플러그인]          [웹 서비스]              [AI 에이전트]
 통합 Extension          →                              
 (네이버페이 + 쿠팡)        웹앱 (React SPA)          
 현대카드 CSV 업로드   →     ↕                       
                          Spring Boot API             
                            ↕                       
                          PostgreSQL                  
                            ↕                       
                          MCP 서버  ←→  사용자의 AI 에이전트
```

### 핵심 흐름

#### 1. 데이터 수집 (브라우저 플러그인 + CSV 업로드)

- 통합 Chrome Extension: 네이버페이/쿠팡 결제내역 페이지에서 거래 데이터 추출
  - 서비스에 로그인되어 있으면 API로 직접 업로드
  - 로그인되어 있지 않으면 기존처럼 엑셀/CSV 다운로드
- 카드사 CSV/엑셀은 웹 서비스에서 수동 업로드 지원

#### 2. Staging 단계

- 플러그인에서 전달받은 데이터는 **staging** 상태로 표시
- 사용자가 staging 데이터를 확인하고:
  - 카테고리 설정 (식비, 교통, 쇼핑, 구독 등)
  - 컨텍스트 설정 (개인, 데이트, 업무 등)
  - 메모 추가
  - 불필요한 항목 제외
- 확정(confirm)하면 가계부에 반영

#### 3. 가계부 관리

- 월별 지출/수입/저축 대시보드
- 카테고리별, 컨텍스트별 지출 분석
- 고정지출 관리 (월세, 구독 등)
- 전월 대비, 전년 동월 대비 비교
- 월별 데이터 CSV/엑셀 다운로드

#### 4. AI 에이전트 연동 (MCP)

- 서비스 백엔드에 MCP 서버를 구성 (REST API 완성 후 래핑)
- 사용자가 자신의 AI 에이전트(Claude, ChatGPT 등)에서 MCP로 연결
- MCP가 제공하는 기능:
  - 월별/카테고리별 지출 데이터 조회
  - 수입/저축/투자 현황 조회
  - 재무 상담 결과를 서비스에 저장
  - CSV 형태로 데이터 제공
- **LLM API 비용은 사용자 부담**: 서비스가 ChatGPT/Claude API를 제공하는 것이 아니라, 사용자가 자신의 API 키로 에이전트를 연결하는 구조

## 수동 워크플로우 가이드

금융 API를 사용할 수 없으므로, 사용자에게 명확한 수동 워크플로우를 안내해야 한다.

### 가이드 대상 워크플로우

| 단계 | 사용자 액션 | 서비스 지원 |
|---|---|---|
| 플러그인 설치 | Chrome 웹스토어에서 설치 | 설치 가이드 제공 |
| 데이터 추출 | 네이버페이/쿠팡 접속 후 플러그인 클릭 | 자동 추출 및 서비스 전송 (로그인 시) |
| 카드 내역 | 카드사 앱/웹에서 CSV 다운로드 후 업로드 | 업로드 UI, 파서 자동 적용 |
| 카테고리 설정 | staging 데이터에 카테고리 지정 | 자동 추천, 규칙 학습 |
| 확정 | 검토 후 확정 버튼 | 가계부 반영 |

### 자동화 가능 영역

- 카테고리 자동 추천 (이전 동일 사용처 기반)
- 고정지출 자동 인식 (반복 패턴)
- 반복 입력 사용처에 대한 규칙 저장

## MCP 서버 설계

REST API 완성 후 래핑하여 구현한다.

### 제공 도구 (Tools)

```
get_monthly_expenses(year, month)       # 월별 지출 내역
get_expenses_by_category(year, month)   # 카테고리별 지출
get_income(year, month)                 # 수입 내역
get_savings(year, month)                # 저축 내역
get_fixed_expenses()                    # 고정지출 목록
get_financial_summary(year, month)      # 재무 요약 (수입-지출-저축)
export_csv(year, month)                 # CSV 형태로 데이터 제공
save_consultation(content, date)        # 에이전트 상담 내용 저장
get_consultation_history()              # 과거 상담 내역 조회
```

### 인증

- 사용자별 API 토큰 발급
- MCP 연결 시 토큰으로 인증
- 자신의 데이터에만 접근 가능

## 기술 스택

### 프론트엔드

- React + Vite (SPA)
- TailwindCSS
- Recharts (차트/그래프)

### 백엔드

- Spring Boot
- PostgreSQL (거래내역, 사용자, 카테고리)
- Redis (카테고리 추천 캐시, 세션)

### 브라우저 플러그인

- Chrome Extension (Manifest V3)
- 네이버페이 + 쿠팡을 하나의 통합 익스텐션으로 개발
- 기존 npay-exporter(https://github.com/juu-n-oo/npay-exporter) 를 확장
- 엑셀/CSV 다운로드 기능 유지 + 서비스 API 업로드 추가
- 서비스 API와 직접 통신

### MCP 서버

- MCP SDK 활용
- 백엔드 REST API를 래핑하여 MCP 프로토콜로 제공

### 인프라

- Kubernetes (익숙한 환경 활용)
- PostgreSQL (호스팅 방식 별도 결정)

## MVP 정의

### Phase 1: 코어 서비스 + 익스텐션 연동

- [ ] 사용자 인증 (회원가입/로그인)
- [ ] CSV/엑셀 파일 업로드 및 파싱 (현대카드, 쿠팡 형식)
- [ ] 크롬 익스텐션 통합 (네이버페이 + 쿠팡)
- [ ] 크롬 익스텐션 → 서비스 API 직접 업로드 연동
- [ ] staging UI: 업로드된 데이터 확인 및 카테고리 설정
- [ ] 확정 후 가계부 반영
- [ ] 수입/저축 수동 입력
- [ ] 월별 지출 대시보드 (카테고리별 시각화)
- [ ] 월별 데이터 CSV/엑셀 다운로드

### Phase 2: 고도화

- [ ] 카테고리 자동 추천 (동일 사용처 기반 규칙)
- [ ] 고정지출 자동 인식 및 관리
- [ ] 전월/전년 동월 비교 분석
- [ ] 카테고리 규칙 학습 고도화
- [ ] 지출 알림 (예산 초과 시)
- [ ] 다크모드
- [ ] 모바일 반응형 최적화

### Phase 3: MCP 및 AI 연동

- [ ] MCP 서버 구현 (REST API 래핑)
- [ ] 사용자별 API 토큰 발급
- [ ] 에이전트 상담 결과 저장 API
- [ ] 상담 히스토리 조회 UI

### Phase 4: 서비스 확장

- [ ] 외부 사용자 대응 (온보딩, 가이드)

- [ ] 추가 플랫폼 지원 확장

## 제외 범위

- 금융 API / 마이데이터 연동
- Next.js SSR (Spring Boot와 역할 중복, SPA로 확정)
- 초기 단계에서의 MCP 구현 (REST API 완성 후 진행)
- LLM API 직접 제공 (사용자가 자신의 API 키로 연결하는 구조)

## 경쟁 서비스 대비 차별점

| 기존 가계부 앱 | 이 서비스 |
|---|---|
| 금융 API 연동 필요 (뱅크샐러드, 토스) | 플러그인 기반, 금융 API 불필요 |
| 서비스가 AI 기능 내장 | MCP로 사용자가 원하는 AI 에이전트 연결 |
| 정해진 카테고리 체계 | 사용자 커스텀 카테고리/컨텍스트 |
| 네이버페이/쿠팡 상세내역 미지원 | 플러그인으로 품목 단위 추출 |
| LLM 비용을 서비스가 부담 | 사용자가 자신의 API 키로 연결 |

## 한계 및 리스크

| 리스크 | 대응 |
|---|---|
| 금융 API 사용 불가 | 플러그인 + CSV 업로드로 우회. 수동 워크플로우를 최대한 간결하게 설계 |
| 플러그인 DOM 변경 취약성 | 파서를 설정 기반으로 분리하여 빠른 대응. 버전 관리 |
| 플랫폼 약관 리스크 | 사용자 본인의 데이터를 본인이 추출하는 구조. 약관 검토 필요 |
| 개인정보 처리 이슈 | 최소한의 데이터만 서버 저장. 개인정보처리방침 작성 |
| 초기 사용자 확보 | 본인이 첫 사용자. 커뮤니티(가계부/재테크) 홍보 |
| MCP 생태계 성숙도 | MCP 표준이 아직 발전 중이므로 REST API도 병행 제공 |

## 수익화 가능성

- **프리미엄 플랜**: 고급 분석, 무제한 히스토리, 다중 가계부
- **추후**: 광고, 금융 상품 추천 (제휴)
- 초기에는 수익화보다 사용자 확보와 서비스 검증에 집중

## 열린 질문

- 쿠팡의 `__NEXT_DATA__` 또는 유사한 SSR 데이터 구조 확인 필요
- 인프라 상세 구성 (K8s 클러스터 환경, DB 호스팅 방식)
- 인증 방식 상세 (OAuth, JWT 등)
- 카테고리 자동 추천 알고리즘의 구체적 구현 방식
