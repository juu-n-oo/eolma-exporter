# eolma exporter - 쿠팡,네이버페이 거래내역 추출 Chrome Web Store 등록 정보

이 문서는 eolma exporter - 쿠팡,네이버페이 거래내역 추출 등록 화면에 입력할 값과 개인정보 보호 신고의 기준 문서다. 코드·개인정보처리방침·스토어 입력값을 함께 바꾼다.

### 짧은 설명

아래 문구는 132자 이하다.

> 네이버페이·쿠팡 주문내역을 Excel·CSV로 내보내거나, 로그인한 본인 eolma 가계부로 전송합니다.

### 상세 설명

```text
eolma exporter - 쿠팡,네이버페이 거래내역 추출은 네이버페이와 쿠팡의 결제·주문내역을 사용자가 원하는 범위로 정리해 Excel 또는 CSV 파일로 내려받을 수 있는 가계부 보조 도구입니다.

■ 할 수 있는 일
• 네이버페이 결제내역과 쿠팡 주문내역 수집
• 월별·기간별·전체 기간 선택
• Excel(.xlsx) 또는 CSV 파일 다운로드
• 사용자가 직접 선택한 경우, 로그인한 본인 eolma 가계부의 검토 대기함으로 전송

■ 사용 방법
1. 네이버페이 또는 쿠팡에 로그인하고 주문내역 페이지를 엽니다.
2. 확장 프로그램 아이콘을 누르고 범위를 선택합니다.
3. Excel·CSV로 내려받거나 eolma로 전송합니다.
4. eolma 전송을 이용하려면 eolma 탭을 열어 로그인한 상태여야 하며, 전송된 내역은 eolma에서 검토 후 확정합니다.

■ 개인정보 보호
• 수집 내역은 사용자가 파일 다운로드 또는 eolma 전송을 직접 요청할 때만 처리합니다.
• eolma로 전송하지 않으면 내역은 브라우저 밖으로 전송되지 않습니다.
• 확장 프로그램은 eolma 로그인 쿠키나 인증 토큰을 읽거나 저장하지 않습니다.
• 결제·주문내역을 광고, 데이터 판매, 금융상품 추천 또는 신용도 평가에 사용하지 않습니다.

eolma는 가계부 도구이며 금융 자문·투자 자문·금융상품 추천을 제공하지 않습니다.
```

## 개인정보 보호 관행 신고

Chrome Web Store 개발자 대시보드의 실제 질문 문구가 바뀔 수 있으므로, 다음 사실을 기준으로 가장 일치하는 항목을 선택한다.

| 항목 | 신고 기준 |
|---|---|
| 단일 목적 | 사용자가 요청한 네이버페이·쿠팡 결제/주문내역의 로컬 파일 내보내기 또는 본인 eolma 계정 전송 |
| 처리 데이터 | 금융·결제 정보와 웹사이트 콘텐츠: 판매자·상품명·금액·일시·주문 상태 등 |
| 인증 정보 | 수집·저장하지 않음. HttpOnly 쿠키는 eolma 탭의 same-origin 요청에만 브라우저가 자동 첨부 |
| 외부 전송 | 이용자가 “eolma로 전송”을 직접 선택한 경우에만 Dandi Works가 운영하는 `https://eolma.de`의 본인 계정으로 전송 |
| 판매·광고·제3자 제공 | 하지 않음 |
| 사람의 열람 | 이용자 지원, 보안 조사, 법령상 필요한 경우에만 최소한으로 가능 |
| 원격 코드 | 사용하지 않음. Excel 라이브러리는 패키지에 포함 |

### 권한별 정당성

| 권한 또는 호스트 | 정당성 |
|---|---|
| `activeTab` | 사용자가 확장 아이콘을 누른 현재 탭이 지원되는 주문내역 페이지인지 확인합니다. |

| `https://eolma.de/*` | 사용자가 로그인해 둔 eolma 탭에서 로그인 상태를 확인하고, 사용자가 직접 요청한 내역만 본인 계정으로 전송합니다. 쿠키·토큰은 읽거나 저장하지 않습니다. |

## 제출 전 확인

1. `bash scripts/package-chrome-store.sh`를 실행해 검증된 ZIP을 만든다.
2. Chrome의 `chrome://extensions`에서 `src/`를 압축 해제해 로드한다.
3. 네이버페이·쿠팡에서 다운로드 흐름을 확인하고, eolma 탭을 열어 로그인한 상태에서만 전송이 가능한지 확인한다.
4. 생성된 `dist/eolma-exporter-v<version>.zip`을 개발자 대시보드에 업로드한다. ZIP 최상위에는 `manifest.json`이 있어야 한다.
5. 이 문서의 개인정보 보호 관행과 권한 정당성을 대시보드에 반영한 뒤 심사에 제출한다.

개발자 계정 등록과 실제 심사 제출은 계정 소유자가 개발자 대시보드에서 진행해야 한다.
