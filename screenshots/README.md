# 스토어 에셋

Chrome 웹 스토어 등록용 이미지. **현재 버전: v0.3.0** (한국어).

> ⚠️ **스크린샷 수동 재생성 필요**: 아래 store/raw/promo 이미지는 아직 **v0.2.0 시점 캡처**다.
> 0.2.3의 플랫폼 tint 버튼과 0.3.0의 수집 취소·상단 버전 표시 등 popup UI가 바뀌었으므로,
> 실제 스토어 갱신 전 아래 "재생성 방법"으로 **0.3.0 popup UI 기준 스크린샷을 수동 재생성**해야 한다.
> (현 작업 환경에 headless Chrome 렌더·합성 파이프라인이 없어 자동 재생성하지 못함.)
> v0.2.0 시점 원본은 `changes/v0.2.0/` 에 보존되어 있다.

### 재생성 방법

실제 `src/popup.html` 의 인라인 CSS 를 추출해 한국어 상태를 구성하고, headless Chrome(`ko-KR`, 2×)으로 렌더한 뒤 1280×800·440×280 으로 다운스케일한다. 폰트·여백·색이 실제 익스텐션과 일치한다. (년월 필드는 헤드리스가 영문으로 렌더해 한국어 Chrome 실제 표시인 "2026년 6월" 로 맞춤. 로그인 사용자명은 데모용 홍길동.)
